# Crypto Agent Bot — Domain Context

## Project Vision
An autonomous multi-agent crypto trading system that discovers, backtests, and executes trading strategies through a 6-layer agent architecture, with minimal human intervention.

## Ubiquitous Language

**Agent System**
- **OrchestratorAgent** — Top-level coordinator that decomposes goals and delegates to sub-agents
- **StrategistAgent** — Generates trading strategy hypotheses using LLM + market context (sentiment, patterns, regime)
- **BacktesterAgent** — Runs Freqtrade backtests on strategist-generated strategies, returns structured metrics
- **RegimeDetector** — Identifies market regime (trending, ranging, volatile) using macro + on-chain signals
- **RiskAgent** — Evaluates position sizing via Kelly Criterion (conservative/compounding/aggressive profiles)
- **ExecutionAgent** — Routes live trades to exchanges via Kraken Pro, with circuit breaker guards
- **ResearcherAgent** — Independent research via API data sources for market context injection
- **MonitorAgent** — Observes system health, anomaly detection, circuit breaker states

**Trading Concepts**
- **Signal** — Technical indicator combination that triggers a trade entry/exit (generated by SignalFactory)
- **SignalFactory** — Generates and pre-filters trading signals using TA-Lib indicators matching Freqtrade strategy templates
- **Regime** — Market state classifier (trending/ranging/volatile) used to filter suitable strategies
- **Kelly Criterion** — Position sizing formula, with conservative/aggressive profiles
- **Circuit Breaker** — Risk guard that halts trading on drawdown or anomaly thresholds
- **Strategy Concept** — LLM-generated idea describing a trading approach (human-readable)
- **Strategy Template** — Freqtrade-compatible Python strategy class generated from a concept

**Data Pipeline**
- **DataDownloader** — Fetches OHLCV + extra data (funding rates, open interest) via CCXT
- **MarketContextInjector** — Gathers sentiment, pattern, regime data before strategist runs
- **SignalScanner** — Scans for active trading opportunities from generated signals
- **Timerange** — Date range for backtests, with sanitizer logic for Freqtrade constraints

**Execution & Risk**
- **PaperTrading** — Simulated execution mode for validating strategies without real capital
- **LiveExecutor** — Routes signals to exchange via Kraken Pro API
- **RiskProfile** — One of conservative/compounding/aggressive, determines Kelly fraction
- **AnomalyDetector** — Monitors for unusual market conditions or system behavior

**Backtesting**
- **BacktestEngine** — Wraps Freqtrade backtesting with metric extraction (Sharpe, drawdown, win rate)
- **WalkForwardValidator** — Walk-forward analysis for time-series robustness
- **CPCVValidator** — Combinatorial Purged Cross-Validation for anti-overfitting (replaces Gate 6)
- **Hyperopt** — Freqtrade hyperparameter optimization
- **BlindParameterSearch** — Parameter search on holdout data to prevent overfitting

**Infrastructure**
- **EventBus** — Async pub/sub event system for inter-agent communication
- **StateBroker** — Key-value + pub/sub state management (in-memory or Redis-backed)
- **TradingDatabase** — SQLite singleton for persistent trade/strategy state
- **CryptoAgentSet** — LangGraph agent set coordinating the autonomous research loop
- **GoalManager** — Decomposes high-level goals into child tasks for async execution

**Data Sources**
- **CCXT** — Unified exchange API layer (Kraken Pro execution, multiple exchange data)
- **Freqtrade** — Backtesting, strategy engine, data download
- **CoinGecko** — Market metrics and sentiment data
- **Santiment** — On-chain and social metrics
- **CoinCap** — Asset price and market data
- **Fear & Greed Index** — Market sentiment indicator
- **CryptoPanic** — News sentiment feed
- **TA-Lib** — Technical analysis indicators (BBANDS, RSI, MACD, etc.)

**UI**
- **Web UI** — React frontend (Babel standalone, no build step)
- **Dashboard** — Bento-grid 4-zone layout with candlestick charts, gauges, signal cards
- **Goal Runner** — UI modal for submitting autonomous goals with real-time terminal log streaming
- **Circuit Breaker UI** — Visual panel showing breaker state and controls

| Tests | `tests/` | pytest suite (~630 tests across all contexts) |

## Key Architectural Decisions

- **Agent orchestration via LangGraph** — ReAct agents with LangGraph for research loop
- **Signal matching with Freqtrade** — SignalFactory uses identical TA-Lib calls as engine templates
- **SQLite singleton pattern** — TradingDatabase uses `__new__` for singleton enforcement
- **Event-driven state** — EventBus + StateBroker for loose coupling between agents
- **Windows deployment** — Asyncio event loop management, file encoding (UTF-8), path handling
- **No frontend build step** — Babel standalone for inline JSX transformation

## Quality Attributes

- **Testability** — pytest with httpx mock pattern for API tests, tmp_path for SQLite tests
- **Observability** — Real-time terminal logging, Web UI streaming, anomaly detection
- **Safety** — Circuit breaker, paper trading mode, Kelly-constrained position sizing
- **Portability** — Cross-platform Python, dependency management via requirements.txt
